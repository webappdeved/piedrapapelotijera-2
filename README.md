## Descripción del Proyecto
Este software desarrolla un entorno interactivo lúdico que demuestra los principios físicos y lógicos de la persistencia de datos no volátil en almacenamiento secundario. Utilizando flujos de streams de entrada/salida (`ifstream` y `ofstream`) en modo de adición (`ios::app`), el sistema resguarda de forma segura los registros estructurados de las partidas mapeadas en un archivo de texto plano sin sobrecargar la pila de memoria del hardware.
